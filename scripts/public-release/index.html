IntegriTest

Google Forms · guided setup

A clear path from quiz to review.

The monitor records observable browser and supported Windows app activity for professor review. An incident is not proof of cheating.

Preview package: v{{VERSION}} currently connects to a teacher service on the same computer at 127.0.0.1:8787. Live Chrome and hosted remote checks are pending. Use this page for local setup only.

Student

  1. Use Windows and Chrome. Download the setup ZIP and compare its SHA-256 checksum.
  2. Extract it. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extension folder inside integritest-v{{VERSION}}. It must contain manifest.json. A missing-manifest error means the outer folder was selected.
  3. In PowerShell from the extracted folder, run powershell -NoProfile -ExecutionPolicy Bypass -File native-host\install.ps1 -ExtensionId amlfomdhhaklmifkneplnngkbaabibgp. Reload the extension.
  4. Enter the one-time code from your professor in the extension popup. Open the Form link shown there, then start monitoring.
  5. Submit the Form and check that monitoring ended. If it remains active after submission, contact your professor. For a technical failure, use Report a problem and stop early; the report marks this separately. Keep the local JSON export if delivery fails.

Professor

  1. Create a Google Form and publish its respondent viewform link.
  2. Run the private local teacher service, register the Form, import a class roster with Student ID and Name columns, and assign it to the exam. Give each student their own code.
  3. Review assigned IDs, last contact, gaps, severity counts, and latest activity in the protected teacher table. Open full incident reports only when needed. Match the roster entry with Google Forms responses separately.

The public remote teacher link will be added after the HTTPS deployment and separate-device check.

What is recorded?

Incident categories, timestamps, supported app categories, and needed website hostnames. The monitor does not collect answers, document contents, full browsing URLs, window titles, or file paths. A gap shows missed contact, not what happened during it.
