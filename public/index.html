Set up a monitored examination

This tool records observable browser and Windows app activity for professor review. An incident is not proof of cheating. Your professor still checks the Form answers separately.

Student

  1. Use a Windows computer and Google Chrome. Download the demo package and compare its published SHA-256 checksum below.
  2. Extract the package. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted extension folder.
  3. In PowerShell from the extracted package folder, run powershell -NoProfile -ExecutionPolicy Bypass -File native-host\install.ps1 -ExtensionId amlfomdhhaklmifkneplnngkbaabibgp. Reload the extension afterward.
  4. Get your one-time code from the professor. Open the extension popup and enter the code. Check that it says paired, then open the Form link shown there.
  5. Start monitoring from the popup before answering. Other open tabs in that Chrome window trigger a warning, but do not block Start.
  6. Submit the Form and check that monitoring ended. If it stays active, click End Examination. Keep the local JSON export as a delivery fallback.

The extension sends incident categories, times, app categories, and needed website hostnames. It does not send answers, document contents, or full browsing URLs. A connection gap means the professor did not receive a heartbeat; it does not establish what happened during that gap.

Professor

  1. Create and publish a Google Form. Add a required Student ID question. Copy its respondent viewform link.
  2. Sign in to the teacher view. Create an exam with the Form link and quiz title.
  3. Enter dummy Student IDs for the demo. Distribute each one-time join code privately to its assigned student.
  4. Watch session status, last contact, and incident timeline. Download the service-generated JSON report after the exam.
  5. Compare the assigned ID with the Student ID in Google Forms responses. The code links a report to an assigned ID, not a verified physical person.

For a local demo, students must reach the same local service. Remote monitoring requires the later HTTPS deployment and separate-device test. Hosted records are scheduled for deletion after 30 days.
