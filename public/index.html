STUDENT

Set up your monitor

Use Windows and Google Chrome.

  1. Download and extract. Get the v0.2.0 setup package and compare its checksum below.
  2. Load the Chrome extension. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted extension folder inside exam-monitor-v0.2.0. Check that this folder contains manifest.json before selecting it. If Chrome says the manifest is missing, you selected the outer folder.
  3. Connect Windows monitoring. In PowerShell from the extracted folder, run:powershell -NoProfile -ExecutionPolicy Bypass -File native-host\install.ps1 -ExtensionId amlfomdhhaklmifkneplnngkbaabibgpReload the extension afterward.
  4. Pair and begin. Enter your one-time code in the extension popup, open the registered Form link shown there, then choose Start Examination.
  5. Finish clearly. Submit the Form and confirm monitoring ended. If it stays active, choose End Examination. Keep the local JSON export if delivery fails.

PROFESSOR

Prepare and review an exam

Keep each class record organized by Form.

  1. Publish a Google Form with a required Student ID question. Copy its respondent viewform link.
  2. Create an exam record in the professor workspace using that Form link.
  3. Assign IDs such as Student 1 and Student 2. Give each student their own one-time code privately.
  4. Review activity under the exam record. Check contact status, incident timeline, and the service-generated JSON report.
  5. Match responses separately. Compare the assigned Student ID with the Google Forms answer. A join code does not verify physical identity.

What the monitor records

Incident categories, timestamps, supported app categories, and needed website hostnames. It does not collect answers, document contents, full browsing URLs, window titles, or file paths. A contact gap shows missed communication, not what happened during it.
